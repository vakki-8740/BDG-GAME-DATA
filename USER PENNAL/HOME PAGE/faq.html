FAQ

DEPOSITE

Deposite kya hai aur isme problem kya hoti hai?

Deposite ka matlab hai aap apne game account me paisa daalte ho. Kabhi kabhi paisa daalne ke baad bhi game account me balance add nahi hota. Is problem ko solve karne ke liye aap Deposite Not Recevie option me apni details submit karte ho.

Deposite ke baad paisa account me kab tak aayega?

Normal deposite turant (instant) game account me add ho jata hai. Agar 10-15 minute tak paisa add nahi hota to problem ho sakti hai. Aap Deposite Submit Page me apni details aur payment image upload karke complaint kar sakte ho.

Deposite status Processing me kyu dikh raha hai?

Processing ka matlab hai aapka paisa humare system me check ho raha hai. Payment verify hone ke baad game account me add kar diya jayega. Kuch time baad balance check karein.

Mera deposite Reject ho gaya hai, kya karna chahiye?

Deposite reject hone ka matlab hai payment me koi problem thi (galat amount, galat screenshot, ya payment confirm nahi hui). Aap Deposite Not Recevie option me form bharke naya complaint karo aur sahi payment image upload karo.

Deposite Failed kyu ho jata hai?

Failed deposite ka matlab hai payment process pura nahi hua. Bank se paisa kat gaya ho lekin game account me nahi aaya ho, to us case me Deposite Not Recevie form bharein aur payment screenshot ke saath submit karein.

Deposite ke liye kya kya details chahiye?

Deposite complaint ke liye aapko Email Id, Game Account Mobile Number, Game Account Password, Deposite Problem type, aur Payment Image (screenshot) chahiye hoti hai.

WITHDRWAL

Withdrawal kya hai aur isme problem kya hoti hai?

Withdrawal ka matlab hai game account se paisa nikal kar apne bank account me lena. Kabhi kabhi withdrawal karne ke baad paisa bank account me nahi aata. Is problem ko solve karne ke liye aap Withdrwal Problem option me apni details submit karte ho.

Withdrawal ke baad paisa bank account me kab tak aayega?

Normal withdrawal 24-48 ghante (1-2 din) ke andar bank account me aa jata hai. Agar isse zyada time lag raha hai to aap Withdrwal Problem form bharke complaint kar sakte ho.

Withdrawal status Processing me kyu dikh raha hai?

Processing ka matlab hai aapka withdrawal request humare system me check ho raha hai. Bank details verify hone ke baad paisa transfer kar diya jayega. Kuch time baad bank balance check karein.

Mera withdrawal Reject ho gaya hai, kya karna chahiye?

Withdrawal reject hone ka matlab hai koi detail galat thi (galat bank details, galat mobile number, ya account verify nahi hai). Aap Withdrwal Problem form bharke complaint karo aur sahi details ke saath submit karo.

Withdrawal Failed kyu ho jata hai?

Failed withdrawal ka matlab hai transfer process pura nahi hua. Game account se paisa cut gaya ho lekin bank account me nahi aaya ho, to us case me Withdrwal Problem form bharein aur issue image ke saath submit karein.

Amount Not Recevie Bank Account kya hai?

Iska matlab hai aapka withdrawal approve ho gaya tha lekin paisa aapke bank account me nahi aaya. Is case me aap Withdrwal Problem form me Amount Not Recevie Bank Account option select karke complaint karo.

Withdrawal ke liye kya kya details chahiye?

Withdrawal complaint ke liye aapko Email Id, Game Account Mobile Number, Game Account Password, Withdrawal Problem type, aur Withdrawal Issue Image chahiye hoti hai.

GAME PROBLEM

Game Problem kya hai?

Game Problem ka matlab hai game khelne ke time aane wali koi bhi dikkat - jaise game open nahi ho raha, game crash ho raha hai, balance galat dikh raha hai, ya koi bhi game se related problem.

Game open nahi ho raha hai, kya karun?

Agar game open nahi ho raha hai to Game Problem form me apni details bharein, apni problem likhein, aur issue image upload karein. Humari team aapki problem solve karegi.

Game ka balance galat dikh raha hai?

Agar game ka balance galat dikh raha hai (kam ya zyada), to Game Problem form me apni problem detail me likhein aur issue image ke saath submit karein. Hum check karke balance sahi karenge.

Game problem ke liye kya kya details chahiye?

Game Problem complaint ke liye aapko Email Id, Game Account Mobile Number, Game Account Password, Problem ke baare me likhna, aur Issue Image chahiye hoti hai.

Complaint submit karne ke baad kya hoga?

Complaint submit karne ke baad humari team aapki problem check karegi aur jald se jald solve karegi. Aapko service center se contact kiya jayega ya problem fix kar di jayegi.

Complaint solve hone me kitna time lagta hai?

Zyada tar complaints 24-48 ghante (1-2 din) me solve ho jati hain. Problem ke hisaab se time kam ya zyada ho sakta hai.
